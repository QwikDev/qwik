# Getting started with Qwik

Qwik renders on the server and resumes on the client, so a page ships only the JavaScript its
interactions need. Start from an empty starter, add a route, and the framework takes care of
splitting the rest.

<PostCallout>

This is a shared component rendered inside an MDX post. The same component is used by every
post in this demo.

</PostCallout>

## What you need

- Node.js 20 or later
- A Qwik starter (`npm create qwik@latest`)
- One route file to edit

Write the route, run the dev server, and the page is live.
